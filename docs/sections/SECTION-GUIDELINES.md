# Section Guidelines

Status: ACTIVE
Last Updated: 2026-10-03
Owner: Nakshatra Core

Every new section must follow this workflow:

1. Inspect reference
2. Define scope
3. Define ownership
4. Define data
5. Define public API
6. Define RSC/client boundary
7. Implement
8. Validate
9. Review
10. Lock

**Rule:** No section should begin with abstraction.\n
