## Design Tokens

Status: OPEN / PARTIALLY DEFINED

Only values explicitly established in the repository or approved architecture documents may be treated as authoritative.

Agents must not invent token values or design-system conventions for:
- Colors
- Typography
- Spacing
- Breakpoints
- Motion tokens
- Component tokens

Currently, Tailwind CSS v4 handles utility classes. Component-specific animations and overrides are managed via CSS Modules.\n
